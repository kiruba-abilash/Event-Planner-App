# Event Planner App

## Project Overview

Event Planner App is a simple and user-friendly mobile application developed using React Native and Expo. It is designed to help users organize and manage their events easily.

## Features

* Simple and user-friendly interface
* Create and view events
* Organize event details
* Mobile-friendly design

## Technologies Used

* React Native
* Expo
* JavaScript
* Visual Studio Code

## Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/Event-Planner-App.git
```

**2. Open the project**

```bash
cd Event-Planner-App
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

```bash
npx expo start
```

**5. Run the app**

Open the application using Expo Go or an Android emulator.

## Project Purpose

This project was developed to improve practical knowledge of React Native mobile application development, UI design, and event management functionality.
